# agency-lab-social-media

Aplicación educativa interactiva para seleccionar canales de social media según objetivos, audiencia y conversión.

## Uso local

Abre `index.html` directamente en un navegador moderno. La aplicación incluye su CSS y JavaScript, funciona sin internet y no requiere instalación, servidor, APIs ni claves.

Conserva los ejemplos Restaurante, Retail y B2B, los seis objetivos de marketing y las pestañas Canales, Ecosistema, Matriz y Presentación.

## Publicación en GitHub Pages

1. Incluye `index.html` y este README en la rama que vayas a publicar.
2. En el repositorio de GitHub, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama que contiene estos archivos y la carpeta **/ (root)**.
4. Guarda la configuración y espera a que GitHub termine la publicación.

No hace falta ejecutar un build. `index.html` debe permanecer en la raíz; sus recursos están incluidos en el propio archivo y no dependen del dominio ni de la ruta de publicación.
